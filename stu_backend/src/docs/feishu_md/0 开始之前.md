对于Java Web编程技术、数据库原理与应用和面向对象系统分析与设计的初学者，综合利用所学知识开发一个系统并不容易。我们决定使用基本的Java Web开发技术：Servlet、JSP、JavaBeans、JDBC、Java Script、EL、JSTL、过滤器、AJAX等开发一个“实验报告提交系统”，并把开发过程记录下来，一方面是为了方便教学中收集学生实验报告，另一方面为学生提供一个完整的开发案例。
实验报告上传系统：
1.  实验教学中，实验要求是以Word文档的形式分发给学生的。学生按照实验要求完成实验内容，编写并提交PDF版本的实验报告;
1. 每门实验课有多个实验项目（如：Servlet程序设计、JSP程序设计、会话程序设计、JDBC数据库访问等）；
1. 每个实验项目要提交一份实验报告，教师会根据实验进度开放和关闭某个实验报告的上传，实验报告必须是PDF文件，大小不超过8M；
1. 每门实验课单独一个文件夹；同一个实验项目的实验报告上传到相同的文件夹中，文件夹以项目名称命名；
1. 不论学生上传的文件名是什么，我们希望均以“学号-姓名-实验项目名.pdf”保存上传文件;
1. “实验报告上传系统”是一个独立的系统，不需要与其他系统对接。教师可以从教学系统下载到实验课学生的花名册，根据花名册中选课学生名单按照Excel表格模板填写“实验课信息”，教师创建课程时通过“实验课信息”Excel表导入实验课的项目和学生信息（项目名称、学生姓姓名和学号）；

1. 用户：
  - DBA：系统运维，数据库管理；
  - 教师：建立实验课程，导入实验项目和学生信息；开放、关闭、截止实验项目的上传；下载实验报告；
  - 学生：上传实验报告。
1. 开发环境：
  - IDE: NetBeans/ VS Code
  - 服务器: Windows或Linux,Tomcat
  - 数据库: SQL Server或者Mysql
