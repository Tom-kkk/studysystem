# **javascipt**
格式1（单行注释）：
```javascript
   //这是一个单行注释注释
```

格式2（多行注释）：
```javascript
   /*注释代码*/
```

# **JAVA的注释三种形式：单行注释、多行注释、文档注释**
格式1（单行注释）：
```java
  //这是一个单行注释
```

格式2（多行注释）：
```java
/*
这是一个多行注释
*/
```


格式3（文档注释）：
```java
/**
@author a_hasaigei
@version 1.0
这是一个文档注释
是用来生成帮助文档的
文档注释，是一种特殊的多行注释
*/
```
